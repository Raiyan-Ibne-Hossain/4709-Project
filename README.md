This paper proposes a novel machine learning-based photovoltaic (PV) system capable of predicting solar irradiance with 
high accuracy and performing maximum power point tracking (MPPT) based on the predicted solar irradiance data. The 
significance of our work is characterized by increasing the solar power generation efficiency and output of any PV system. 
A successful model for accurate solar irradiance forecast is developed using different prediction models like Multiple Linear Regression, Random Forest Regression, and MLP. Particle 
swarm optimisation (PSO) algorithm utilises this forecast data which helps to determine MPPT values for that PV system. 
Our work produces results having an R2 value of 0.9999, meaning that the model offers a desirably high level of accuracy.
